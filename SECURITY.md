# Security policy

I have included security controls and tests for important cases, including tenant access and unsafe webhook destinations. This project has not had an independent security audit.

If you find a vulnerability, please use GitHub’s private vulnerability reporting feature if it is enabled. Please do not post credentials or a working exploit against a live deployment in a public issue.

The [security guide](docs/security.md) explains the controls and their limits. The GitHub configuration includes Dependabot and CodeQL checks.
